Formulario

¿Que son los formularios?

Los formularios web son uno de los principales puntos de interacción entre un usuario y un sitio web o aplicación. Los formularios permiten a los usuarios la

introducción de datos, que generalmente se envían a un servidor web para su procesamiento y almacenamiento o se usan en el lado del cliente para provocar

de alguna manera una actualización inmediata de la interfaz

Se utiliza un formulario HTML para recopilar la información que introduce el usuario. Esta información se suele enviar a un servidor para su procesamiento.

Elementos del Formulario

El elemento <"form>

El elemento HTML <"form> se utiliza para crear un formulario HTML para la entrada de datos por parte del usuario:

Este <"form> elemento es un contenedor para diferentes tipos de elementos de entrada, como campos de texto, casillas de verificación,

botones de opción, botones de envío, etc.

El elemento <"input>

El elemento HTML <"input> es el elemento de formulario más utilizado.

Un <"input> elemento puede mostrarse de muchas maneras, dependiendo del type atributo.

Tipo Descripcion
<´input type="text"> Muestra un campo de entrada de texto de una sola línea.
<´input type="radio"> Muestra un botón de opción (para seleccionar una de varias opciones).
<´input type="checkbox"> Muestra una casilla de verificación (para seleccionar cero o más de varias opciones).
<´input type="submit"> Muestra un botón de envío (para enviar el formulario).
<´input type="button"> Muestra un botón en el que se puede hacer clic.

El elemento <´label>

La <´label> etiqueta define una etiqueta para muchos elementos de formulario.

Este <´label> elemento resulta útil para los usuarios de lectores de pantalla, ya que el lector de pantalla leerá en voz alta la etiqueta

cuando el usuario se centre en el elemento de entrada.

Este <´label> elemento también ayuda a los usuarios que tienen dificultades para hacer clic en regiones muy pequeñas (como botones de opción

o casillas de verificación), ya que cuando el usuario hace clic en el texto dentro del <´label>elemento, se activa o desactiva el botón de

opción o la casilla de verificación.

El foratributo de la <´label> etiqueta debe ser igual al idatributo del <´input> elemento para vincularlos.
