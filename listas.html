Listas

¿Que es una lista?

Las listas en HTML son elementos estructurados que sirven para organizar y mostrar grupos de información relacionada en forma de viñetas o números

¿como funciona una lista?

Una lista en HTML funciona agrupando elementos de texto mediante etiquetas contenedoras (<"ul> u <"ol>) que le indican al navegador web

cómo estructurar el contenido, mientras que cada renglón se crea con una etiqueta de elemento (<"li>).

Etiquetas principales

  • <"ul>: Define el inicio y el final de una lista desordenada.
  • <"ol>: Define el inicio y el final de una lista ordenada.
  • <"li>: Representa cada elemento individual dentro de una lista <"ul> o <"ol>.
  • <"dl>: Define una lista de descripción.
  • <"dt>: Indica el término a definir.
  • <"dd>: Proporciona la descripción del término.

Tipos de listas

Listas desordenadas (<"ul>)
- Muestran elementos con viñetas (puntos) cuando el orden de la información no importa.
Lista ordenada (<"ol>")
- Muestran elementos numerados (con números, letras o números romanos) cuando la secuencia o el orden sí importan.
Lista de definicíon (<"dl>)
- Agrupan términos (<"dt>) junto con sus respectivas descripciones o explicaciones (<"dd>).

Lista Desordenada

Una lista no ordenada comienza con la <"ul> etiqueta. Cada elemento de la lista comienza con la <"li>etiqueta.

Ejemplo

  • Café
  • Té
  • Leche

Lista Ordenada

Una lista ordenada comienza con la <"ol> etiqueta. Cada elemento de la lista comienza con la <"li> etiqueta.

Ejemplo

  1. Café
  2. Té
  3. Leche

Lista de Descripción

Una lista descriptiva es una lista de términos, con una descripción de cada término.

La <"dl> etiqueta define la lista de descripción, la <"dt> etiqueta define el término (nombre) y la <"dd> etiqueta describe cada término:

Ejemplo

Café
- bebida caliente negra
Leche
- bebida fría blanca
